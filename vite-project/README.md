# 🎯 Portfólio Profissional - Felipe Trevizam

Portfólio profissional moderno desenvolvido com React, TypeScript e Vite, apresentando a trajetória acadêmica e profissional de Felipe Trevizam, pesquisador e desenvolvedor especializado em Engenharia de Manufatura e Ciência de Dados.

## 🎨 Características

- **Design Responsivo**: Interface adaptada para desktop, tablet e mobile
- **Interface Moderna**: Componentes estilizados com Styled Components
- **Animações Suaves**: Transições e animações para melhor UX
- **Performance Otimizada**: Vite para build rápida
- **TypeScript**: Tipagem estática completa
- **Componentes Reutilizáveis**: Arquitetura modular

## 🚀 Inicio Rápido

### Pré-requisitos

- Node.js 18+ instalado
- npm ou yarn

### Instalação

1. Clonar o repositório

```bash
git clone <seu-repositorio>
cd vite-project
```

2. Instalar dependências

```bash
npm install
```

3. Configurar variáveis de ambiente

```bash
cp .env.example .env
```

4. Iniciar o servidor de desenvolvimento

```bash
npm run dev
```

A aplicação será aberta em `http://localhost:5173`
